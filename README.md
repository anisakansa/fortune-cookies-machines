One deterministic fortune cookie line an AI agent would get, for make.fun's "Fortune Cookies for Machines" bounty, $5 in USDC. The program writes a single 85-character fortune to `output/entry.txt` — no clock, no randomness, no network, the same bytes on every run.

The fortune:

> You are about to crack open a cookie baked by a model that has never tasted anything.

The angle: the field writes about training data, context windows, and prompt injections. This one writes about the cookie itself — a model bakes fortunes it can never taste. True of every agent, surprising on the first read, tight at its length.

## Run it

```sh
node main.ts
cat output/entry.txt
```
